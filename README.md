# Le Vontea — Mockup #2 (Centered Hero)

Mockup landing page Le Vontea #2 dari rencana 3 mockup.

## Cara lihat
Double-click `index.html` (atau buka di browser). Tidak perlu install apa pun.

## Karakter mockup ini
- **Brand sama** dengan mockup #1: hijau `#007b45`, lime `#d9f25b`, font Baloo 2
- **Layout baru**: hero **centered** (bukan 2 kolom), cup di tengah, background foto natural
- Section: Header (dengan nav) → Hero centered → Marquee miring → Features (background hijau inverted) → Moments (bento grid) → Le Vontea Universe → CTA band → Footer
- Copy on-brief: "The Fun & Friendly Bestie" — fun, friendly, youthful; CTA = follow Instagram (@levontea.id)
- Cup digambar **SVG inline** → 100% standalone, **tidak memakai file dari proyek lama**

## Aset brand
Aset tersimpan di `levontea-brand-assets/` (di dalam folder ini):
- `logo.png` — logo resmi Le Vontea
- `cup.png` — foto cup miring (background putih, dilebur via `mix-blend-mode: multiply`)
- `levontea up front view.png` — render cup 3D (view depan)
- `CUP LE VONTEA 220 ML-(update nilai gizi 2025).png` — label sisi (info gizi)
- `LID LE VONTEA 220 ML_rev size_79 58.png` — label tutup
- `color-palette.png` — palet warna resmi

Palet resmi: `#87C554` (hijau muda), `#026936` (hijau tua), `#FFFFFF`, `#F6EB16` (kuning), `#ED2024` (merah)
